# Datasets

This folder contains the datasets used by the demos.

## Dances

The dances dataset is a collection of dances performed by the [Pollen Robotics](https://pollen-robotics.com/) team.

It is hosted on the [Hugging Face Hub](https://huggingface.co/pollen-robotics/reachy-mini-dances-library).

### Downloading the dances dataset

You can download the dances dataset using the following command:

```bash
hf download pollen-robotics/reachy-mini-dances-library --repo-type dataset --local-dir datasets/dances
```

This will download the dances dataset to the `datasets/dances` folder.
